Сварочное производство
Нагрев, плавление, тепловые потери
Сварщик
📘 Задача 1. Работа газа при сварке
Ситуация: При сварке в баллоне объёмом $V = 40$ л газ изобарно расширяется при давлении $p = 10^5$ Па, его объём увеличивается на $\Delta V = 0{,}5$ л. Найдите работу газа.
📌 Дано: $p = 10^5$ Па, $\Delta V = 0{,}5$ л $= 5 \cdot 10^{-4}$ м³
🔍 Найти: $A$
Шаг 1. Работа газа при изобарном процессе: $A = p \cdot \Delta V$.
Шаг 2. $A = 10^5 \cdot 5 \cdot 10^{-4} = 50 \text{ Дж}$
Пояснение: Небольшое расширение газа в баллоне совершает работу всего 50 Дж — этого недостаточно для существенных изменений.
✅ Ответ: $A = 50$ Дж
📘 Задача 2. КПД нагрева при сварке
Ситуация: При сварке выделилось $Q_1 = 10000$ Дж теплоты. Из них в изделие ушло только $Q_{полезн} = 6000$ Дж. Найдите КПД процесса нагрева.
📌 Дано: $Q_1 = 10000$ Дж, $Q_{полезн} = 6000$ Дж
🔍 Найти: $\eta$
Шаг 1. Формула: $\eta = \dfrac{Q_{полезн}}{Q_1}$.
Шаг 2. $\eta = \dfrac{6000}{10000} = 0{,}6 = 60\%$
Пояснение: 40% теплоты потеряно: ушло в окружающую среду, на нагрев воздуха и т.д.
✅ Ответ: $\eta = 60\%$
📘 Задача 3. Тепловой баланс при сварке СЛОЖНАЯ
Ситуация: При сварке деталь массой $m = 0{,}5$ кг из стали (удельная теплоёмкость $c = 500$ Дж/(кг·К)) нагревается от $t_1 = 20$ °C. Выделилось $Q = 50$ кДж теплоты, КПД процесса $\eta = 60\%$. Найдите: а) полезную теплоту; б) конечную температуру детали; в) потери теплоты в окружающую среду.
📌 Дано: $m = 0{,}5$ кг, $c = 500$ Дж/(кг·К), $t_1 = 20$ °C, $Q = 50000$ Дж, $\eta = 0{,}6$
🔍 Найти: $Q_{пол}$, $t_2$, $Q_{пот}$
Шаг 1 (полезная теплота). $Q_{пол} = \eta \cdot Q = 0{,}6 \cdot 50000 = 30000$ Дж.
Шаг 2 (нагрев детали). $Q_{пол} = cm\Delta t \Rightarrow \Delta t = \dfrac{Q_{пол}}{cm}$.
$\Delta t = \dfrac{30000}{500 \cdot 0{,}5} = \dfrac{30000}{250} = 120 \text{ °C}$
Шаг 3. Конечная температура: $t_2 = 20 + 120 = 140$ °C.
Шаг 4 (потери). $Q_{пот} = Q - Q_{пол} = 50000 - 30000 = 20000$ Дж.
Пояснение: Треть теплоты уходит в атмосферу. Поэтому при сварке важно защищать зону нагрева от потерь.
✅ Ответ: $Q_{пол} = 30$ кДж; $t_2 = 140$ °C; $Q_{пот} = 20$ кДж
📘 Задача 4. Изменение внутренней энергии ДЛЯ САМОСТОЯТЕЛЬНОГО РЕШЕНИЯ
Ситуация: При сварке газ в замкнутом объёме получил $Q = 2000$ Дж теплоты. Работа газа не совершается ($V = \text{const}$). На сколько изменилась его внутренняя энергия?
💡 Подсказка: Изохорный процесс ($V = \text{const}$), поэтому $A = 0$. Первое начало: $\Delta U = Q$. Ответ — 2000 Дж.
📘 Задача 5. Работа при расширении газа ДЛЯ САМОСТОЯТЕЛЬНОГО РЕШЕНИЯ
Ситуация: Газ в баллоне при давлении $p = 5 \cdot 10^5$ Па изобарно расширяется от $V_1 = 2$ л до $V_2 = 5$ л. Найдите работу газа.
💡 Подсказка: $A = p(V_2 - V_1)$. Не забудьте перевести литры в м³: 2 л = 0,002 м³, 5 л = 0,005 м³. Ответ — 1500 Дж.

Электрик
📘 Задача 1. Изменение внутренней энергии проводника
Ситуация: При протекании тока проводник получил $Q = 500$ Дж теплоты. Работа не совершается. Найдите изменение внутренней энергии и температуры, если масса $m = 0{,}1$ кг, $c = 400$ Дж/(кг·К).
📌 Дано: $Q = 500$ Дж, $m = 0{,}1$ кг, $c = 400$ Дж/(кг·К)
🔍 Найти: $\Delta U$, $\Delta T$
Шаг 1. $A = 0$, поэтому $\Delta U = Q = 500$ Дж.
Шаг 2. $\Delta T = \dfrac{Q}{cm} = \dfrac{500}{400 \cdot 0{,}1} = \dfrac{500}{40} = 12{,}5$ К.
Пояснение: Вся теплота пошла на нагрев проводника. Температура выросла на 12,5 °C.
✅ Ответ: $\Delta U = 500$ Дж; $\Delta T = 12{,}5$ К
📘 Задача 2. КПД электродвигателя
Ситуация: Электродвигатель совершил полезную работу $A = 8000$ Дж, затратив $Q = 10000$ Дж электроэнергии. Найдите КПД.
📌 Дано: $A = 8000$ Дж, $Q = 10000$ Дж
🔍 Найти: $\eta$
Шаг 1. $\eta = \dfrac{A}{Q}$.
Шаг 2. $\eta = \dfrac{8000}{10000} = 0{,}8 = 80\%$
Пояснение: Потери 20% — это нагрев обмоток (джоулево тепло) и трение в подшипниках.
✅ Ответ: $\eta = 80\%$
📘 Задача 3. Тепловой баланс в электрощите СЛОЖНАЯ
Ситуация: В трансформаторном отсеке работают два прибора: один выделяет $Q_1 = 500$ Дж/с, второй $Q_2 = 300$ Дж/с. Отсек имеет вентиляцию, отводящую $Q_{отв} = 600$ Дж/с. Найдите: а) общее тепловыделение; б) накопление теплоты в отсеке за $t = 60$ с; в) изменение температуры воздуха массой $m = 50$ кг за это время ($c = 1005$ Дж/(кг·К)).
📌 Дано: $Q_1 = 500$ Дж/с, $Q_2 = 300$ Дж/с, $Q_{отв} = 600$ Дж/с, $t = 60$ с, $m = 50$ кг, $c = 1005$ Дж/(кг·К)
🔍 Найти: $Q_{общ}$, $\Delta Q$, $\Delta T$
Шаг 1 (общее тепловыделение). $Q_{общ} = Q_1 + Q_2 = 800$ Дж/с.
Шаг 2 (накопление). Разница между выделением и отводом: $Q_{ост} = 800 - 600 = 200$ Дж/с.
Шаг 3. За $t = 60$ с накопится $\Delta Q = 200 \cdot 60 = 12000$ Дж.
Шаг 4 (нагрев воздуха). $\Delta T = \dfrac{\Delta Q}{cm} = \dfrac{12000}{1005 \cdot 50} \approx 0{,}239$ К.
Пояснение: Вентиляция почти справляется, но из-за превышения выделения над отводом воздух всё равно нагреется. При длительной работе температура может стать критичной.
✅ Ответ: $Q_{общ} = 800$ Дж/с; $\Delta Q = 12$ кДж; $\Delta T \approx 0{,}24$ К
📘 Задача 4. Работа при нагреве провода ДЛЯ САМОСТОЯТЕЛЬНОГО РЕШЕНИЯ
Ситуация: Проводник получил $Q = 2000$ Дж теплоты и совершил работу $A = 500$ Дж (за счёт расширения). Найдите изменение внутренней энергии.
💡 Подсказка: Первое начало: $\Delta U = Q - A = 2000 - 500$. Ответ — 1500 Дж.
📘 Задача 5. КПД нагревательного прибора ДЛЯ САМОСТОЯТЕЛЬНОГО РЕШЕНИЯ
Ситуация: Электронагреватель потребляет $Q = 12000$ Дж, полезно передаёт воде $Q_{пол} = 9600$ Дж. Найдите КПД.
💡 Подсказка: $\eta = \dfrac{Q_{пол}}{Q} = \dfrac{9600}{12000}$. Ответ — 80%.

Автомеханик
📘 Задача 1. КПД двигателя
Ситуация: Двигатель получил от сгорания топлива $Q_1 = 40000$ Дж теплоты и совершил работу $A = 12000$ Дж. Найдите КПД.
📌 Дано: $Q_1 = 40000$ Дж, $A = 12000$ Дж
🔍 Найти: $\eta$
Шаг 1. $\eta = \dfrac{A}{Q_1}$.
Шаг 2. $\eta = \dfrac{12000}{40000} = 0{,}3 = 30\%$
Пояснение: Это типичный КПД ДВС. Остальные 70% теплоты уходят в выхлопные газы и систему охлаждения.
✅ Ответ: $\eta = 30\%$
📘 Задача 2. Теплота, отданная холодильнику
Ситуация: Двигатель получает $Q_1 = 50000$ Дж, КПД $\eta = 35\%$. Найдите полезную работу и теплоту, отданную в атмосферу.
📌 Дано: $Q_1 = 50000$ Дж, $\eta = 0{,}35$
🔍 Найти: $A$, $Q_2$
Шаг 1. $A = \eta \cdot Q_1 = 0{,}35 \cdot 50000 = 17500$ Дж.
Шаг 2. $Q_2 = Q_1 - A = 50000 - 17500 = 32500$ Дж.
Пояснение: Более половины теплоты уходит в атмосферу — поэтому двигатели греются и нуждаются в радиаторе.
✅ Ответ: $A = 17{,}5$ кДж; $Q_2 = 32{,}5$ кДж
📘 Задача 3. Полный анализ работы двигателя СЛОЖНАЯ
Ситуация: Двигатель работает по циклу Карно между температурами $T_1 = 900$ К и $T_2 = 400$ К. За цикл от нагревателя получено $Q_1 = 8000$ Дж. Найдите: а) КПД; б) полезную работу; в) теплоту, отданную холодильнику; г) как изменится КПД, если $T_2$ уменьшить до 300 К.
📌 Дано: $T_1 = 900$ К, $T_2 = 400$ К, $Q_1 = 8000$ Дж
🔍 Найти: $\eta$, $A$, $Q_2$, $\eta'$ (при $T_2 = 300$ К)
Шаг 1 (КПД). $\eta = \dfrac{900 - 400}{900} = \dfrac{500}{900} \approx 0{,}556 = 55{,}6\%$
Шаг 2 (работа). $A = 0{,}556 \cdot 8000 \approx 4444$ Дж.
Шаг 3 (теплота холодильнику). $Q_2 = 8000 - 4444 = 3556$ Дж.
Шаг 4 (при $T_2 = 300$ К). $\eta' = \dfrac{900 - 300}{900} = \dfrac{600}{900} \approx 0{,}667 = 66{,}7\%$
Пояснение: Снижение температуры холодильника с 400 до 300 К повысило КПД с 55,6% до 66,7%. Это один из способов повышения эффективности двигателя.
✅ Ответ: $\eta \approx 55{,}6\%$; $A \approx 4{,}4$ кДж; $Q_2 \approx 3{,}6$ кДж; $\eta' \approx 66{,}7\%$
📘 Задача 4. Работа газа в цилиндре ДЛЯ САМОСТОЯТЕЛЬНОГО РЕШЕНИЯ
Ситуация: В цилиндре двигателя газ изобарно расширяется при давлении $p = 8 \cdot 10^5$ Па от $V_1 = 0{,}05$ л до $V_2 = 0{,}2$ л. Найдите работу газа за такт расширения.
💡 Подсказка: $A = p(V_2 - V_1)$. Перевести литры в м³: 0,05 л = 5·10⁻⁵ м³, 0,2 л = 2·10⁻⁴ м³. Ответ — 120 Дж.
📘 Задача 5. Сравнение КПД двух двигателей ДЛЯ САМОСТОЯТЕЛЬНОГО РЕШЕНИЯ
Ситуация: Двигатель №1 получает $Q_1 = 10000$ Дж и совершает работу $A_1 = 3000$ Дж. Двигатель №2 получает $Q_2 = 15000$ Дж и совершает работу $A_2 = 6000$ Дж. Какой КПД выше?
💡 Подсказка: $\eta_1 = 3000/10000 = 30\%$; $\eta_2 = 6000/15000 = 40\%$. Второй двигатель эффективнее.

Машиностроение
📘 Задача 1. КПД паровой турбины
Ситуация: Паровая турбина получает пар с температурой $T_1 = 750$ К, отработанный пар имеет температуру $T_2 = 350$ К. Найдите максимально возможный КПД (цикл Карно).
📌 Дано: $T_1 = 750$ К, $T_2 = 350$ К
🔍 Найти: $\eta_{max}$
Шаг 1. $\eta_{max} = \dfrac{T_1 - T_2}{T_1}$.
Шаг 2. $\eta_{max} = \dfrac{750 - 350}{750} = \dfrac{400}{750} \approx 0{,}533 = 53{,}3\%$
Пояснение: Реальные паровые турбины имеют КПД 35–45% — ниже идеального цикла Карно из-за трения и потерь.
✅ Ответ: $\eta_{max} \approx 53{,}3\%$
📘 Задача 2. Полезная работа турбины
Ситуация: Турбина получает $Q_1 = 100000$ Дж теплоты от пара и отдаёт холодильнику $Q_2 = 60000$ Дж. Найдите КПД и полезную работу.
📌 Дано: $Q_1 = 100000$ Дж, $Q_2 = 60000$ Дж
🔍 Найти: $\eta$, $A$
Шаг 1. $A = Q_1 - Q_2 = 40000$ Дж.
Шаг 2. $\eta = \dfrac{A}{Q_1} = \dfrac{40000}{100000} = 40\%$.
Пояснение: 40% теплоты превращается в работу — это типичный КПД турбины. Остальные 60% рассеиваются в конденсаторе.
✅ Ответ: $\eta = 40\%$; $A = 40$ кДж
📘 Задача 3. Оптимизация теплового двигателя СЛОЖНАЯ
Ситуация: Тепловой двигатель работает по циклу Карно. Инженер хочет повысить КПД с 40% до 50%. Начальные температуры: $T_1 = 500$ К, $T_2 = 300$ К. Найдите: а) на сколько нужно повысить $T_1$ при неизменном $T_2$; б) на сколько нужно понизить $T_2$ при неизменном $T_1$. Какой способ эффективнее?
📌 Дано: $T_1 = 500$ К, $T_2 = 300$ К, $\eta_1 = 40\%$, $\eta_2 = 50\%$
🔍 Найти: $\Delta T_1$, $\Delta T_2$
Шаг 1 (повышение $T_1$). $\eta = 1 - \dfrac{T_2}{T_1} = 0{,}5 \Rightarrow \dfrac{T_2}{T_1} = 0{,}5 \Rightarrow T_1 = \dfrac{T_2}{0{,}5} = 600$ К.
$\Delta T_1 = 600 - 500 = 100 \text{ К}$
Шаг 2 (понижение $T_2$). $\dfrac{T_2}{500} = 0{,}5 \Rightarrow T_2 = 250$ К.
$\Delta T_2 = 300 - 250 = 50 \text{ К}$
Пояснение: Понизить $T_2$ на 50 К проще, чем повысить $T_1$ на 100 К. Но на практике оба способа ограничены свойствами материалов и окружающей среды.
✅ Ответ: $\Delta T_1 = 100$ К или $\Delta T_2 = 50$ К; второй способ энергетически выгоднее
📘 Задача 4. Идеальный КПД ДЛЯ САМОСТОЯТЕЛЬНОГО РЕШЕНИЯ
Ситуация: Газовая турбина работает между $T_1 = 1500$ К и $T_2 = 700$ К. Найдите максимально возможный КПД.
💡 Подсказка: $\eta_{max} = \dfrac{T_1 - T_2}{T_1} = \dfrac{800}{1500}$. Ответ — около 53%.
📘 Задача 5. Теплота топлива ДЛЯ САМОСТОЯТЕЛЬНОГО РЕШЕНИЯ
Ситуация: Двигатель мощностью $P = 50$ кВт работает в течение $t = 1$ часа с КПД $\eta = 25\%$. Сколько теплоты выделилось при сгорании топлива?
💡 Подсказка: Полезная работа $A = P \cdot t = 50000 \cdot 3600 = 1{,}8 \cdot 10^8$ Дж. Тогда $Q = \dfrac{A}{\eta}$. Ответ — $7{,}2 \cdot 10^8$ Дж.

📘 Задача 1. Тепловыделение процессора
Ситуация: Процессор выделяет $Q = 80$ Вт тепла. Какое количество теплоты выделится за $t = 30$ минут работы?
📌 Дано: $Q = 80$ Вт, $t = 30$ мин $= 1800$ с
🔍 Найти: $Q_{общ}$
Шаг 1. $Q_{общ} = Q \cdot t$.
Шаг 2. $Q_{общ} = 80 \cdot 1800 = 144000 \text{ Дж} = 144 \text{ кДж}$
Пояснение: За 30 минут процессор выделяет 144 кДж тепла. Это сравнимо с нагревом 1 литра воды на 34 °C.
✅ Ответ: $Q_{общ} = 144$ кДж
📘 Задача 2. КПД системы охлаждения
Ситуация: Система охлаждения отводит $Q_{отв} = 36000$ Дж тепла из $Q_{общ} = 40000$ Дж, выделяемых сервером. Найдите КПД системы охлаждения.
📌 Дано: $Q_{общ} = 40000$ Дж, $Q_{отв} = 36000$ Дж
🔍 Найти: $\eta$
Шаг 1. $\eta = \dfrac{Q_{отв}}{Q_{общ}}$.
Шаг 2. $\eta = \dfrac{36000}{40000} = 0{,}9 = 90\%$
Пояснение: Система отводит 90% теплоты — хороший показатель. Оставшиеся 10% накапливаются в корпусе, повышая температуру.
✅ Ответ: $\eta = 90\%$
📘 Задача 3. Тепловой баланс дата-центра СЛОЖНАЯ
Ситуация: Дата-центр содержит $N = 50$ серверов по $P = 500$ Вт каждый. Система охлаждения работает как тепловой насос: затрачивает $P_{охл} = 10$ кВт, отводит 90% всего тепла. Найдите: а) общее тепловыделение серверов; б) отведённое тепло; в) КПД системы; г) итоговое тепловыделение в помещение.
📌 Дано: $N = 50$, $P = 500$ Вт, $P_{охл} = 10000$ Вт, $\eta_{отв} = 0{,}9$
🔍 Найти: $Q_{серв}$, $Q_{отв}$, $\eta$, $Q_{ост}$
Шаг 1. Общее тепловыделение серверов: $Q_{серв} = 50 \cdot 500 = 25000$ Вт = 25 кВт.
Шаг 2. С учётом системы охлаждения: общее выделение $Q_{общ} = 25000 + 10000 = 35000$ Вт.
Шаг 3. Отведено: $Q_{отв} = 0{,}9 \cdot 35000 = 31500$ Вт = 31,5 кВт.
Шаг 4. КПД: $\eta = 0{,}9 = 90\%$.
Шаг 5. Остаётся в помещении: $Q_{ост} = 35000 - 31500 = 3500$ Вт = 3,5 кВт.
Пояснение: Даже при отводе 90% остаётся 3,5 кВт — это требует дополнительной вентиляции, иначе температура будет расти.
✅ Ответ: $Q_{серв} = 25$ кВт; $Q_{отв} = 31{,}5$ кВт; $\eta = 90\%$; $Q_{ост} = 3{,}5$ кВт
📘 Задача 4. Работа при нагреве воздуха в корпусе ДЛЯ САМОСТОЯТЕЛЬНОГО РЕШЕНИЯ
Ситуация: Воздух в герметичном корпусе сервера получил $Q = 1000$ Дж теплоты, при этом совершил работу расширения $A = 300$ Дж. Найдите изменение внутренней энергии.
💡 Подсказка: Первое начало: $\Delta U = Q - A = 1000 - 300$. Ответ — 700 Дж.
📘 Задача 5. КПД охлаждающей системы ДЛЯ САМОСТОЯТЕЛЬНОГО РЕШЕНИЯ
Ситуация: Кондиционер в серверной затрачивает $P_1 = 5$ кВт электроэнергии, чтобы отвести $P_2 = 20$ кВт тепла. Найдите эффективность системы (как отношение отведённого тепла к затраченной энергии).
💡 Подсказка: Это холодильный коэффициент: $\varepsilon = \dfrac{P_2}{P_1} = \dfrac{20}{5}$. Ответ — 4. Чем больше, тем эффективнее.
